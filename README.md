## Getting Started

### Prerequisites
- Node.js >= 18
- npm >= 9

### Installation
```bash
./scripts/setup.sh
```

### Development
```bash
npm run dev
```

### Testing
```bash
npm test
```

### Deployment
```bash
./scripts/deploy.sh
```
